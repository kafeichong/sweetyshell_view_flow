## 📞 紧急联系

### 服务器问题排查流程
1. 检查系统负载：`uptime`
2. 检查内存使用：`free -h`
3. 检查磁盘空间：`df -h`
4. 检查容器状态：`docker ps -a`
5. 查看日志：`docker logs <container> --tail 100`
6. 重启服务：`docker restart <container>`

### 常见问题
**Q: 容器无法启动？**
```bash
# 查看详细错误
docker logs <container_name>

# 检查端口占用

# 检查配置文件
docker inspect <container_name>
```

**Q: 磁盘空间不足？**
```bash

docker system prune -a

# 查找大文件
du -sh /data/* | sort -rh | head -10
```

**Q: 服务无响应？**
