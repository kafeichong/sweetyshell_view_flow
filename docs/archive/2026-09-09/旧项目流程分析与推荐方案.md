## 一、旧项目的实际实现（已验证）

### 完整数据流：

```python
# 文件：packages/worker/executor.py (行 240-290)

1. 创建任务（Backend → Provider API）
   adapter.create_task(params)
   → 返回：provider_task_id

2. 更新状态为 RUNNING
   update_job_status(job.id, JobStatus.RUNNING)

3. 轮询 Provider 直到完成
   task_status = adapter.poll_until_complete(provider_task_id)
   → 返回：ProviderTaskStatus {
       status: "completed",
       result_url: "https://ark.cn-beijing.volces.com/..."  # Provider 临时 URL
   }

4. 从 Provider URL 下载到 Worker 本地
   adapter.download_video(task_status.result_url, local_path)
   → 保存到：/path/to/output/IMAGE_TO_VIDEO-20260909-143025.mp4

5. 上传到 OSS（阿里云）
   oss_url = oss_uploader.upload(local_path, object_key)
   → object_key: "videos/2026/09/09/IMAGE_TO_VIDEO-20260909-143025.mp4"
   → 返回：OSS 签名 URL（有效期 7 天）

6. 创建 Asset 记录（保存到数据库）
   create_asset(
       job_id,
       oss_url,        # file_path: OSS URL
       local_path,     # local_path: 本地路径
       file_type="video"
   )

7. 更新 Job 状态为 COMPLETED
   update_job_status(job.id, JobStatus.COMPLETED)
```

## 二、关键发现

### 发现 1：OSS 签名 URL 有效期只有 7 天 ⚠️

```python
# packages/worker/oss_uploader.py (行 6)
SIGNED_URL_EXPIRE_SECONDS = 7 * 24 * 60 * 60  # 7 天

# 问题：
# 7 天后 OSS URL 过期 → 创意无法访问视频
# 但文件还在 OSS 上，只是签名 URL 过期了
```

**解决方案**：
```python
# 方案 A：延长签名时间（不推荐，有安全风险）
SIGNED_URL_EXPIRE_SECONDS = 365 * 24 * 60 * 60  # 1 年

# 方案 B：OSS Bucket 设为公共读（推荐）
# 直接返回公网 URL，无需签名
oss_url = f"https://{bucket_name}.{region}.aliyuncs.com/{object_key}"

# 方案 C：动态生成签名 URL（按需）
# 数据库保存 object_key，访问时实时生成签名 URL
```

---

### 发现 2：本地文件未删除

```python
# 下载到本地后上传 OSS

await adapter.download_video(result_url, local_path)
```

### 发现 4：Asset 表同时保存了 OSS URL 和本地路径

```python
# packages/worker/executor.py (行 268-273)
```

```text
    ↓

    ↓

    ↓
ComfyUI 显示下载按钮 / 在线播放
【永久保存】
```

## 四、数据模型设计（基于旧项目改进）

### Task 表（改进版）

```typescript
model Task {
  id              String      @id @default(uuid())
  
  userId          String
  user            User        @relation(fields: [userId], references: [id])
  
  // Workflow 信息
  workflowName    String      // "Image → Video"
  workflowVersion String?     // "1.0.0"
  
  // 任务模式（新增）
  mode            TaskMode    @default(PREVIEW)
  
  // 任务状态
  status          TaskStatus  @default(PENDING)
  
  // Provider 相关
  provider        String?     // "seedance"
  model           String?     // "doubao-seedance-2-5-260628"
  providerTaskId  String?     // Provider 返回的任务 ID
  providerUrl     String?     // Provider 临时 URL（Preview 模式用）
  
  // OSS 相关（Production 模式）
  ossUrl          String?     // OSS 永久 URL
  ossObjectKey    String?     // OSS 对象键（用于重新生成签名 URL）
  
  // ComfyUI 相关（如果启用）
  promptId        String?     @unique
  
  // 任务参数
  params          Json        // { prompt, duration, ratio, ... }
  
  // 费用
  cost            Float?
  costStatus      String?     // "confirmed" | "unavailable"
  
  // 时间戳
  createdAt       DateTime    @default(now())
  completedAt     DateTime?
  expiresAt       DateTime?   // Provider URL 过期时间（7天后）
  
  // 关联
  assets          Asset[]
}

enum TaskMode {
  PREVIEW       // 快速预览（不保存）
  PRODUCTION    // 正式生成（保存到 OSS）
}

enum TaskStatus {
  PENDING       // 等待 Worker 处理
  RUNNING       // Provider 处理中
  COMPLETED     // 完成（有 providerUrl 或 ossUrl）
  FAILED        // 失败
}
```

### Asset 表（简化版）

```typescript
model Asset {

  createdAt   DateTime   @default(now())
  
  @@index([taskId])
}

enum AssetType {
  IMAGE
  VIDEO
  AUDIO
}
```

## 六、ComfyUI 自定义节点设计

### 节点 1：创建任务

```python
# ComfyUI Custom Node: AI_Studio_Create_Task

class AIStudioCreateTask:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "mode": (["preview", "production"],),
                "workflow_name": ("STRING", {"default": "Image → Video"}),
                "prompt": ("STRING", {"multiline": True}),
                "image": ("IMAGE",),  # ComfyUI 图片输入
                "duration": ("INT", {"default": 5, "min": 1, "max": 15}),
                "ratio": (["16:9", "9:16", "1:1"],),
            }
        }
    
    RETURN_TYPES = ("STRING",)  # 返回 task_id
    FUNCTION = "create_task"
    CATEGORY = "AI Studio"
    
    def create_task(self, mode, workflow_name, prompt, image, duration, ratio):
        # 1. 上传图片到 OSS（如果还没上传）
        image_url = self.upload_image_to_oss(image)
        
        # 2. 调用 Backend API
        response = requests.post(
            "http://backend-url/api/tasks",
            json={
                "mode": mode,
                "workflowName": workflow_name,
                "params": {
                    "prompt": prompt,
                    "image_url": image_url,
                    "duration": duration,
                    "ratio": ratio
                }
            }
        )
        
        task_id = response.json()["taskId"]
        return (task_id,)
```

### 节点 2：等待任务完成

```python
# ComfyUI Custom Node: AI_Studio_Wait_Task

class AIStudioWaitTask:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "task_id": ("STRING",),
            }
        }
    
    RETURN_TYPES = ("STRING", "STRING")  # (video_url, status)
    FUNCTION = "wait_task"
    CATEGORY = "AI Studio"
    
    def wait_task(self, task_id):
        # 轮询 Backend API 直到完成
        while True:
            response = requests.get(f"http://backend-url/api/tasks/{task_id}")
            data = response.json()
            
            if data["status"] == "completed":
                video_url = data.get("ossUrl") or data.get("providerUrl")
                return (video_url, "completed")
            elif data["status"] == "failed":
                return ("", "failed")
            
            time.sleep(3)  # 每 3 秒查询一次
```

## 八、回答你最初的问题

### 问题：保存 OSS 再传给 ComfyUI 还是直接传给 ComfyUI？

**答案**：基于旧项目分析，推荐**混合方案**

```text
Preview 模式：
  Provider URL → 直接给 ComfyUI（不保存 OSS）
  优点：快、省钱
  缺点：7天后过期

Production 模式：
  Provider URL → Worker 下载 → OSS → 删除本地 → OSS URL 给 ComfyUI
  优点：永久保存、可追溯
  缺点：慢一点、OSS 费用
```

### 关键要点：

1. ✅ **旧项目已经实现了 Production 流程**
   - 下载 → OSS → Asset
   - 只需修复 2 个 bug（签名过期、本地文件未删除）

2. ✅ **只需新增 Preview 流程**
   - 不下载、不上传 OSS
   - 直接返回 Provider URL

3. ✅ **ComfyUI 都是在线加载视频**
   - Preview：从 Provider URL 加载
   - Production：从 OSS URL 加载
   - 不需要下载到创意电脑本地（除非他们主动下载）
