## 二、实事求是的方案

### 方案：简单直接版

```typescript
/**
 * 基于实际业务的上传逻辑
 */
async function uploadMedia(file: File): Promise<UploadResult> {
  // 1. 判断文件类型
  const isInputAsset = file.type.startsWith('image/') || 
                       file.type.startsWith('audio/');
  
  const isVideo = file.type.startsWith('video/');
  
  // ========== 输入素材（产品图、参考视频、音频）==========
  if (isInputAsset) {
    // 计算完整哈希（无论文件多大）
    const fileHash = await calculateFullHash(file);
    
    // 检查是否已存在
    const checkResult = await fetch('/api/media/check', {
      method: 'POST',
      body: JSON.stringify({ fileHash })
    });
    
    const { exists, mediaId, ossUrl } = await checkResult.json();
    
    if (exists) {
      // ✅ 秒传
      return { 
        mediaId, 
        ossUrl, 
        fromCache: true,
        message: '文件已存在，秒传成功' 
      };
    }
    
    // 上传新文件
    return uploadNewFile(file, fileHash);
  }
  
  // ========== 生成的视频 ==========
  if (isVideo) {
    // ❌ 不去重，直接上传
    // 理由：
    // 1. 生成的视频几乎不会重复
    // 2. 计算大文件哈希慢（3-5秒）
    // 3. 去重收益小
    return uploadNewFile(file, null);
  }
}

/**
 * 计算完整哈希（标准做法）
 */
async function calculateFullHash(file: File): Promise<string> {
  const buffer = await file.arrayBuffer();
  const hashBuffer = await crypto.subtle.digest('SHA-256', buffer);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}
```

### 为什么这样设计？

#### 1. 产品图/参考素材：完整哈希去重

**理由**：
- ✅ 文件小（1-5 MB），计算快（< 100 ms）
- ✅ 重复率高（80%），去重收益大
- ✅ 标准做法，100% 准确

**实际性能**：
```text
产品图（3 MB）：
- 计算哈希：50-80 ms
- 查询数据库：5 ms
- 总耗时：< 100 ms

用户体验：✅ 感觉不到延迟
```

**去重效果**：
```text
场景：10 个任务用同一张产品图

不去重：
- 上传 10 次
- OSS 存储：3MB × 10 = 30MB
- 上传时间：10 × 2秒 = 20秒

去重后：
- 上传 1 次
- OSS 存储：3MB × 1 = 3MB
- 上传时间：2秒（第一次）+ 0.1秒 × 9（秒传）= 2.9秒

节约：90% 存储 + 85% 时间
```

---

#### 2. 参考视频（5-50 MB）：完整哈希去重

**理由**：
- ⚠️ 文件稍大，计算稍慢（1-3 秒）
- ✅ 但也会重复使用（参考运镜）
- ✅ 去重收益中等

**实际性能**：
```text
参考视频（30 MB）：
- 计算哈希：1-2 秒
- 查询数据库：5 ms
- 总耗时：< 2 秒

用户体验：✅ 可接受（显示进度条）
```

**UI 体验**：
```text
上传参考视频...

[进度条]
████████████████████░░░░  80%
正在验证文件...

（等 1-2 秒，用户可以接受）
```

---

#### 3. 生成的视频（10-150 MB）：不去重

**理由**：
- ❌ 文件大，计算慢（3-10 秒）
- ❌ 几乎不会重复（每次参数不同）
- ❌ 去重收益极小

**实际情况**：
```text
生成的视频重复概率：
- 理论：需要完全相同的（产品图 + Prompt + 参数）
- 实际：< 1%（创意不会提交完全相同的任务）

即使重复：
- 1 年可能有 50 个重复视频
- 节约存储：50 × 50MB = 2.5GB
- 但计算哈希浪费：9,000 × 5秒 = 12.5 小时

结论：❌ 不值得
```

## 三、数据模型（简化版）

### MediaLibrary 表

```typescript
model MediaLibrary {
  id            String      @id @default(uuid())
  
  // ========== 核心字段 ==========
  fileHash      String      @unique  // ✅ 只对输入素材计算
  fileName      String
  fileType      MediaType   // INPUT_IMAGE, INPUT_VIDEO, INPUT_AUDIO, OUTPUT_VIDEO
  
  // ========== OSS 信息 ==========
  ossUrl        String
  ossObjectKey  String
  fileSize      Int
  
  // ========== 元数据 ==========
  metadata      Json?
  
  // ========== 使用统计 ==========
  usageCount    Int         @default(0)
  
  // ========== 上传信息 ==========
  uploadedBy    String
  createdAt     DateTime    @default(now())
  
  @@index([fileHash])
  @@index([fileType])
}

enum MediaType {
  INPUT_IMAGE      // 产品图（需要去重）
  INPUT_VIDEO      // 参考视频（需要去重）
  INPUT_AUDIO      // 参考音频（需要去重）
  OUTPUT_VIDEO     // 生成的视频（不去重）
}
```

### Backend API

```typescript
// POST /api/media/upload

@Post('upload')
@UseInterceptors(FileInterceptor('file'))
async uploadFile(
  @UploadedFile() file: Express.Multer.File,
  @Body('fileHash') fileHash: string | null,  // ← 可以为 null（OUTPUT_VIDEO）
  @Body('fileType') fileType: MediaType,
  @CurrentUser() user: User
) {
  // 1. 输入素材：检查去重
  if (fileType !== 'OUTPUT_VIDEO' && fileHash) {
    const existing = await prisma.mediaLibrary.findUnique({
      where: { fileHash }
    });
    
    if (existing) {
      // ✅ 秒传
      await prisma.mediaLibrary.update({
        where: { id: existing.id },
        data: { usageCount: { increment: 1 } }
      });
      
      return {
        mediaId: existing.id,
        ossUrl: existing.ossUrl,
        fromCache: true
      };
    }
  }
  
  // 2. 上传到 OSS
  const ossObjectKey = generateObjectKey(fileType, fileHash || uuid());
  const ossUrl = await ossService.upload(file.buffer, ossObjectKey);
  
  // 3. 保存到数据库
  const media = await prisma.mediaLibrary.create({
    data: {
      fileHash: fileHash || null,  // OUTPUT_VIDEO 为 null
      fileName: file.originalname,
      fileType,
      ossUrl,
      ossObjectKey,
      fileSize: file.size,
      uploadedBy: user.id
    }
  });
  
  return {
    mediaId: media.id,
    ossUrl: media.ossUrl,
    fromCache: false
  };
}
```

### 💡 不需要的优化

❌ **采样哈希**（头+中+尾）
- 理由：文件都不大，完整哈希够快

❌ **快速检查**（文件名+大小）
- 理由：数据量小，直接算哈希也很快

❌ **Web Worker 后台计算**
- 理由：计算够快（< 100ms），不需要

❌ **后端异步计算**
- 理由：前端计算更快，用户体验更好
