## 技术说明

### 数据流向
```
任务创建 → 预算预占(reserved) → 任务完成 → 费用结算(settled)
                                              ↓
                              ConsumptionService.getTrends() 直接查询
                                              ↓
                                         前端趋势图展示
```

### 无需额外回填的原因
- `TaskBudgetReservation`表已经是消费数据的主存储表
- `settled`状态的记录就是实际消费记录
- 趋势分析服务直接从该表读取，无需额外的聚合表
- 当任务完成并结算后，数据会自动可用于趋势展示
