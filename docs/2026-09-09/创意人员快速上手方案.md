## 二、3 个方案（从简单到复杂）

### 方案 1：共享你的服务器（最简单，推荐）⭐⭐⭐⭐⭐

#### 架构

```text
你的电脑（服务端）
├── Backend
├── Worker  
├── PostgreSQL
└── Web 管理后台

创意电脑（客户端）
└── 浏览器访问 → http://你的IP:3001
```

#### 优点
- ✅ 创意只需要浏览器
- ✅ 不需要装任何软件
- ✅ 今天就能用

#### 缺点
- ⚠️ 你的电脑要一直开着
- ⚠️ 需要在同一局域网

#### 实施步骤（1 小时）

**Step 1：让你的服务可以被访问**

```bash
# 1. 查看你的局域网 IP
ifconfig | grep "inet " | grep -v 127.0.0.1
# 假设是：192.168.1.100

# 2. 修改 Backend 允许跨域
# packages/backend/src/main.ts
async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  
  // 添加 CORS
  app.enableCors({
    origin: '*',  // 生产环境改为具体域名
    credentials: true
  });
  
  await app.listen(3000, '0.0.0.0');  // ← 监听所有网络接口
}

# 3. 修改 Web 的 API 地址
# packages/web/.env.local
NEXT_PUBLIC_API_URL=http://192.168.1.100:3000/api

# 4. Web 也要监听所有网络接口
# packages/web/package.json
{
  "scripts": {
    "dev": "next dev -H 0.0.0.0"
  }
}

# 5. 重启服务
cd packages/backend && pnpm dev
cd packages/web && pnpm dev
```

**Step 2：创意访问**

```text
创意打开浏览器：
http://192.168.1.100:3001

就能看到你的管理后台了！
```

**Step 3：测试**

```text
创意在界面上：
1. 点击"创建任务"
2. 输入 Prompt
3. 上传产品图
4. 点击"提交"
5. 看到任务在执行
6. 下载生成的视频

完成！
```

### 方案 2：Docker 一键部署（中等）⭐⭐⭐⭐

#### 架构

```text
创意电脑（独立运行）
└── Docker 容器
    ├── Backend
    ├── Worker
    ├── PostgreSQL
    └── Web 管理后台

通过 Docker Compose 一键启动
```

#### 优点
- ✅ 创意完全独立
- ✅ 一键启动
- ✅ 环境隔离

#### 缺点
- ⚠️ 需要装 Docker
- ⚠️ 需要配置 API Key

#### 实施步骤（1-2 天）

**Step 1：编写 Dockerfile**

```dockerfile
# packages/backend/Dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package.json pnpm-lock.yaml ./
RUN npm install -g pnpm && pnpm install
COPY . .
RUN pnpm build
CMD ["pnpm", "start:prod"]

# packages/worker/Dockerfile
FROM python:3.13-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["python", "main.py"]

# packages/web/Dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package.json pnpm-lock.yaml ./
RUN npm install -g pnpm && pnpm install
COPY . .
RUN pnpm build
CMD ["pnpm", "start"]
```

**Step 2：完整 docker-compose.yml**

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: ai_studio
      POSTGRES_PASSWORD: dev_password
      POSTGRES_DB: ai_studio
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"

  backend:
    build: ./packages/backend
    depends_on:
      - postgres
    environment:
      DATABASE_URL: postgresql://ai_studio:dev_password@postgres:5432/ai_studio
    ports:
      - "3000:3000"

  worker:
    build: ./packages/worker
    depends_on:
      - backend
    environment:
      BACKEND_URL: http://backend:3000
      SEEDANCE_API_KEY: ${SEEDANCE_API_KEY}
    volumes:
      - ./output:/app/output

  web:
    build: ./packages/web
    depends_on:
      - backend
    environment:
      NEXT_PUBLIC_API_URL: http://localhost:3000/api
    ports:
      - "3001:3000"

volumes:
  postgres_data:
```

**Step 3：创建启动脚本**

```bash
# start.sh
#!/bin/bash

echo "🚀 启动 AI Studio..."

# 检查 .env 文件
if [ ! -f .env ]; then
  echo "❌ 请先创建 .env 文件，配置 SEEDANCE_API_KEY"
  exit 1
fi

# 启动服务
docker-compose up -d

# 等待服务启动
echo "⏳ 等待服务启动..."
sleep 10

# 检查健康状态
docker-compose ps

echo "✅ 启动完成！"
echo "📱 访问：http://localhost:3001"
```

**Step 4：给创意人员的包**

```bash
# 打包脚本

  docker-compose.yml \

  README-创意人员.md

# 创意人员操作：
# 1. 解压 ai-studio-portable.tar.gz
# 2. 创建 .env 文件，填入 SEEDANCE_API_KEY
# 3. 运行 ./start.sh
# 4. 访问 http://localhost:3001
```

### 方案 3：ComfyUI 插件（最优雅）⭐⭐⭐⭐⭐

#### 架构

```text
创意电脑
└── ComfyUI Desktop
    └── 安装你的自定义节点
        ├── AI Studio Create Task 节点
        ├── AI Studio Wait Task 节点
        └── AI Studio Display Video 节点

后台服务（你的电脑或云服务器）
└── Backend + Worker + DB
```

#### 优点
- ✅ 创意用熟悉的 ComfyUI
- ✅ 无缝集成
- ✅ 最佳用户体验

#### 缺点
- ⚠️ 需要开发 ComfyUI 插件（1-2 周）
- ⚠️ 需要创意装 ComfyUI

#### 实施步骤（1-2 周）

**Step 1：创建 ComfyUI 自定义节点**

```python
# ComfyUI/custom_nodes/ai_studio_nodes.py

import requests

class AIStudioCreateTask:
    """创建 AI Studio 任务节点"""
    
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "prompt": ("STRING", {"multiline": True}),
                "duration": ("INT", {"default": 5, "min": 4, "max": 15}),
                "ratio": (["16:9", "9:16", "1:1"],),
            }
        }
    
    RETURN_TYPES = ("STRING",)  # 返回 task_id
    FUNCTION = "create_task"
    CATEGORY = "AI Studio"
    
    def create_task(self, image, prompt, duration, ratio):
        # 1. 上传图片到后端
        image_url = self.upload_image(image)
        
        # 2. 调用 Backend API 创建任务
        response = requests.post(
            "http://192.168.1.100:3000/api/jobs",
            json={
                "capability": "IMAGE_TO_VIDEO",
                "providerProfile": "seedance-main",
                "params": {
                    "prompt": prompt,
                    "image_url": image_url,
                    "duration": duration,
                    "ratio": ratio
                }
            }
        )
        
        task_id = response.json()["id"]
        print(f"✅ 任务已创建: {task_id}")
        
        return (task_id,)


class AIStudioWaitTask:
    """等待任务完成节点"""
    
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "task_id": ("STRING",),
            }
        }
    
    RETURN_TYPES = ("STRING",)  # 返回 video_url
    FUNCTION = "wait_task"
    CATEGORY = "AI Studio"
    
    def wait_task(self, task_id):
        import time
        
        print(f"⏳ 等待任务完成: {task_id}")
        
        while True:
            response = requests.get(
                f"http://192.168.1.100:3000/api/jobs/{task_id}"
            )
            
            task = response.json()
            status = task["status"]
            
            if status == "completed":
                video_url = task["resultUrl"]
                print(f"✅ 任务完成！视频: {video_url}")
                return (video_url,)
            
            elif status == "failed":
                raise Exception(f"❌ 任务失败: {task.get('errorMessage')}")
            
            print(f"   状态: {status}")
            time.sleep(3)


class AIStudioDisplayVideo:
    """显示/下载视频节点"""
    
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "video_url": ("STRING",),
            }
        }
    
    RETURN_TYPES = ("VIDEO",)
    FUNCTION = "display_video"
    CATEGORY = "AI Studio"
    
    def display_video(self, video_url):
        import os
        import requests
        
        # 下载视频到 ComfyUI output 目录
        output_dir = os.path.join(os.path.dirname(__file__), "../../output")
        os.makedirs(output_dir, exist_ok=True)
        
        filename = f"ai_studio_{int(time.time())}.mp4"
        filepath = os.path.join(output_dir, filename)
        
        print(f"📥 下载视频: {video_url}")
        
        response = requests.get(video_url, stream=True)
        with open(filepath, "wb") as f:
            for chunk in response.iter_content(chunk_size=8192):
                f.write(chunk)
        
        print(f"✅ 已保存: {filepath}")
        
        return (filepath,)


# 注册节点
NODE_CLASS_MAPPINGS = {
    "AI Studio Create Task": AIStudioCreateTask,
    "AI Studio Wait Task": AIStudioWaitTask,
    "AI Studio Display Video": AIStudioDisplayVideo,
}
```

**Step 2：创意使用**

```text

2. 把 ai_studio_nodes.py 放到 custom_nodes/
3. 重启 ComfyUI
4. 在节点菜单看到 "AI Studio" 分类
5. 拖拽节点组合 Workflow：
   [Load Image] → [AI Studio Create Task]

   → [AI Studio Display Video]
```

## 六、常见问题

### Q: 创意访问不了？
**A:** 检查：
1. 你的电脑和创意在同一 Wi-Fi 吗？
2. 你的防火墙是否阻止了端口 3000/3001？
3. IP 地址是否正确？

### Q: 上传图片失败？
**A:** 检查 Backend 的文件上传限制

### Q: 任务一直 pending？
**A:** 检查 Worker 是否在运行
