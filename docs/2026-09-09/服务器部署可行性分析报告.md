## 三、潜在问题分析

### ❌ 高风险问题

#### 问题 1：硬编码的本地路径

**Worker 配置** (`config.py`):
```python
comfyui_output_dir: str = "/path/to/comfyui/output"  # ← 硬编码！
```

**影响**：Worker 启动会失败

**解决方案**：
```python
# 改为从环境变量读取
comfyui_output_dir: str = os.getenv("COMFYUI_OUTPUT_DIR", "/app/output")
```

---

#### 问题 2：CORS 配置

**Backend** (`main.ts`):
```typescript
app.enableCors({
  origin: process.env.NODE_ENV === 'production' ? false : '*',
  //                                               ↑ 生产环境禁用！
});
```

**影响**：生产环境 Web 无法访问 Backend API

**解决方案**：
```typescript
app.enableCors({
  origin: process.env.CORS_ORIGIN?.split(',') || '*',
  credentials: true
});

// .env
CORS_ORIGIN=https://video.你的域名.com,http://服务器IP:3101
```

---

#### 问题 3：数据库迁移

**当前状态**：不确定有没有运行过 `prisma migrate`

**风险**：服务器部署时数据库表不存在

**解决方案**：
```bash
# 部署前必须检查
cd packages/backend
npx prisma migrate status

# 如果有待执行的迁移
npx prisma migrate deploy
```

---

### ⚠️ 中等风险问题

#### 问题 4：端口冲突

**当前端口**：
- Backend: 3000
- Worker: 8001
- PostgreSQL: 5432

**风险**：服务器上可能有其他项目占用这些端口（特别是 SweetyShell 项目）

**解决方案**：
```yaml
# docker-compose.yml 改端口
services:
  backend:
    ports:
      - "3100:3000"  # 外部 3100，内部 3000
  
  worker:
    ports:
      - "8101:8001"
  
  postgres:
    ports:
      - "5433:5432"  # 避免和 SweetyShell 的 5432 冲突
```

---

#### 问题 5：OSS 凭证安全

**当前** (`.env` 文件中明文)：
```env
OSS_ACCESS_KEY_ID=你的阿里云AccessKey_ID
OSS_ACCESS_KEY_SECRET=你的阿里云AccessKey_Secret
```

**风险**：凭证泄露

**解决方案**：
```bash
# 服务器上创建独立的 .env 文件
# 权限设置为 600（只有 root 可读）
chmod 600 /data/video-flow/.env
```

#### 问题 6：日志管理

**当前**：日志输出到 stdout

**风险**：Docker 容器重启后日志丢失

**解决方案**：
```yaml

services:
  backend:
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"
```

## 五、Docker 化改造需求

### 5.1 Backend Dockerfile

**需要创建**：
```dockerfile
FROM node:20-alpine

WORKDIR /app

# 安装 pnpm
RUN npm install -g pnpm

# 复制依赖文件
COPY package.json pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile

# 复制代码
COPY . .

# 生成 Prisma Client
RUN npx prisma generate

# 构建
RUN pnpm build

# 暴露端口
EXPOSE 3000

# 启动命令
CMD ["pnpm", "start:prod"]
```

---

### 5.2 Worker Dockerfile

**需要创建**：
```dockerfile
FROM python:3.13-slim

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    gcc \
    && rm -rf /var/lib/apt/lists/*

# 复制依赖文件
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制代码
COPY . .

# 创建输出目录
RUN mkdir -p /app/output

# 暴露端口
EXPOSE 8001

# 启动命令
CMD ["python", "main.py"]
```

### 5.3 完整 docker-compose.yml

**需要创建**：
```yaml
version: '3.8'

services:
  # PostgreSQL 数据库（独立）
  video-postgres:
    image: postgres:16-alpine
    container_name: video-flow-postgres
    restart: unless-stopped
    environment:
      POSTGRES_USER: video_user
      POSTGRES_PASSWORD: ${DB_PASSWORD}
      POSTGRES_DB: video_flow
    volumes:
      - video_postgres_data:/var/lib/postgresql/data
    ports:
      - "5433:5432"  # 避免冲突
    networks:
      - video-network
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U video_user"]
      interval: 10s
      timeout: 5s
      retries: 5

  # Backend API
  video-backend:
    build:
      context: ./packages/backend
      dockerfile: Dockerfile
    container_name: video-flow-backend
    restart: unless-stopped
    depends_on:
      video-postgres:
        condition: service_healthy
    environment:
      DATABASE_URL: postgresql://video_user:${DB_PASSWORD}@video-postgres:5432/video_flow
      NODE_ENV: production
      JWT_SECRET: ${JWT_SECRET}
      OSS_ACCESS_KEY_ID: ${OSS_ACCESS_KEY_ID}
      OSS_ACCESS_KEY_SECRET: ${OSS_ACCESS_KEY_SECRET}
      OSS_BUCKET: ${OSS_BUCKET}
      OSS_REGION: ${OSS_REGION}
      CORS_ORIGIN: ${CORS_ORIGIN}
    ports:
      - "3100:3000"
    networks:
      - video-network
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"

  # Worker
  video-worker:
    build:
      context: ./packages/worker
      dockerfile: Dockerfile
    container_name: video-flow-worker
    restart: unless-stopped
    depends_on:
      - video-backend
    environment:
      BACKEND_URL: http://video-backend:3000
      VOLCENGINE_ACCESS_KEY: ${VOLCENGINE_ACCESS_KEY}
      OSS_ACCESS_KEY_ID: ${OSS_ACCESS_KEY_ID}
      OSS_ACCESS_KEY_SECRET: ${OSS_ACCESS_KEY_SECRET}
      OSS_BUCKET: ${OSS_BUCKET}
      OSS_REGION: ${OSS_REGION}
      COMFYUI_ENABLED: false
      COMFYUI_OUTPUT_DIR: /app/output
    volumes:
      - video_output:/app/output
    ports:
      - "8101:8001"
    networks:
      - video-network
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"

  # Web 管理后台
  video-web:
    build:
      context: ./packages/web
      dockerfile: Dockerfile
    container_name: video-flow-web
    restart: unless-stopped
    depends_on:
      - video-backend
    environment:
      NEXT_PUBLIC_API_URL: http://${SERVER_IP}:3100/api
      NODE_ENV: production
    ports:
      - "3101:3000"
    networks:
      - video-network
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"

volumes:
  video_postgres_data:
  video_output:

networks:
  video-network:
    driver: bridge
```

## 六、部署流程

### 6.1 服务器准备

```bash
# 1. SSH 登录服务器
ssh root@你的服务器IP

# 2. 安装 Docker
curl -fsSL https://get.docker.com | sh

# 3. 安装 Docker Compose
apt-get update && apt-get install -y docker-compose-plugin

# 4. 创建项目目录
mkdir -p /data/video-flow
cd /data/video-flow
```

---

### 6.2 代码部署

```bash
# 方式 1：Git（推荐）
cd /data/video-flow
git clone <你的仓库地址> repo
cd repo

# 方式 2：直接上传（临时）
# 在本地打包
cd /Users/steven/mylab/video_works
tar -czf video-flow.tar.gz --exclude=node_modules --exclude=venv .

# 上传到服务器
scp video-flow.tar.gz root@服务器IP:/data/video-flow/
ssh root@服务器IP "cd /data/video-flow && tar -xzf video-flow.tar.gz"
```

---

### 6.3 环境变量配置

```bash
# 创建 .env 文件
cat > /data/video-flow/repo/.env << 'EOF'
# 数据库
DB_PASSWORD=<生成强密码>

# JWT
JWT_SECRET=<生成随机密钥>

# 火山引擎
VOLCENGINE_ACCESS_KEY=<你的 API Key>

# 阿里云 OSS
OSS_ACCESS_KEY_ID=<你的 Access Key>
OSS_ACCESS_KEY_SECRET=<你的 Secret>
OSS_BUCKET=sweetyshell-ai-assets
OSS_REGION=oss-cn-beijing

# CORS
CORS_ORIGIN=http://服务器IP:3101

# 服务器 IP
SERVER_IP=你的服务器IP
EOF

# 设置权限
chmod 600 /data/video-flow/repo/.env
```

---

### 6.4 启动服务

```bash
cd /data/video-flow/repo

# 1. 构建镜像
docker compose build

# 2. 启动服务
docker compose up -d

# 3. 检查状态
docker compose ps

# 4. 查看日志
docker compose logs -f

# 5. 运行数据库迁移
docker compose exec video-backend npx prisma migrate deploy
```

---

### 6.5 验证部署

```bash
# 1. 检查 Backend 健康
curl http://localhost:3100/api

# 2. 检查 Worker 健康
curl http://localhost:8101/health

# 3. 访问 Web
# 浏览器打开：http://服务器IP:3101
```
