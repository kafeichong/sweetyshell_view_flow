# 图片/文件相同性判断技术方案

> 设计日期：2026-09-09  
> 核心问题：如何准确判断两个文件是否完全相同？

---

## 一、问题场景

### 场景 1：完全相同的文件

```text
张三上传：product.jpg (1024x1024, 1MB)
李四上传：product_copy.jpg (1024x1024, 1MB)

问题：这两个文件内容完全一样吗？
- 文件名不同 ✗
- 文件大小相同 ✓ （但不够准确）
- 文件内容相同？← 需要判断
```

---

### 场景 2：看起来一样，但实际不同

```text
原图：product.jpg
处理后：product_compressed.jpg （微信压缩后）

外观：人眼看起来一样
实际：
- 文件大小不同（压缩了）
- 像素数据不同（有损压缩）
- EXIF 信息不同（元数据被删除）

这算"同一张图"吗？← 业务决策
```

---

### 场景 3：完全不同的文件

```text
product_a.jpg (化妆品瓶)
product_b.jpg (手机壳)

这肯定是不同的图片 ✓
```

## 二、判断方法对比

### 方法 1：文件名判断 ❌ 不可靠

```typescript
// ❌ 错误示例
function isSameFile(file1: File, file2: File): boolean {
  return file1.name === file2.name;
}

// 问题：
product.jpg !== product_copy.jpg  // 内容相同，文件名不同
product.jpg === product.jpg       // 文件名相同，内容可能不同
```

**结论**：❌ 完全不可靠

---

### 方法 2：文件大小判断 ❌ 不够准确

```typescript
// ❌ 不够准确
function isSameFile(file1: File, file2: File): boolean {
  return file1.size === file2.size;
}

// 问题：
product_a.jpg (1MB) === product_b.jpg (1MB)  // 大小相同，内容不同
```

**结论**：❌ 会误判（两个不同的文件可能大小相同）

---

### 方法 3：文件哈希判断 ✅ 推荐

```typescript
// ✅ 准确方法
async function isSameFile(file1: File, file2: File): Promise<boolean> {
  const hash1 = await calculateFileHash(file1);
  const hash2 = await calculateFileHash(file2);
  return hash1 === hash2;
}

async function calculateFileHash(file: File): Promise<string> {
  const buffer = await file.arrayBuffer();
  const hashBuffer = await crypto.subtle.digest('SHA-256', buffer);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}

// 结果：
product.jpg      → hash: "a1b2c3d4..."
product_copy.jpg → hash: "a1b2c3d4..."  // ✅ 相同！
product_a.jpg    → hash: "a1b2c3d4..."
product_b.jpg    → hash: "e5f6g7h8..."  // ✅ 不同！
```

**原理**：
- 读取文件的**每一个字节**
- 计算哈希值（数字指纹）
- 只要有**一个字节不同**，哈希值就完全不同

**结论**：✅ **最准确**（碰撞概率几乎为 0）

## 三、文件哈希详解

### 3.1 什么是哈希？

```text
哈希（Hash）= 文件的"数字指纹"

原理：
1. 读取文件的每一个字节
2. 通过哈希算法（SHA-256）计算
3. 生成固定长度的字符串（64 个字符）

特点：
✅ 唯一性：不同文件的哈希几乎不可能相同
✅ 确定性：同一文件的哈希永远相同
✅ 不可逆：无法从哈希还原文件内容
✅ 雪崩效应：改变 1 个字节，哈希完全不同
```

---

### 3.2 实际例子

```bash
# 文件 1
echo "产品从水面浮现" > file1.txt
sha256sum file1.txt
# 输出: a1b2c3d4e5f6... (64位十六进制)

# 文件 2（内容完全相同）
echo "产品从水面浮现" > file2.txt
sha256sum file2.txt
# 输出: a1b2c3d4e5f6... (完全相同！)

# 文件 3（只改了一个字）
echo "产品从水面缓缓浮现" > file3.txt
sha256sum file3.txt
# 输出: 9z8y7x6w5v4u... (完全不同！)
```

**图片也一样**：

```bash
# 原图
sha256sum product.jpg
# a1b2c3d4e5f6...

# 重命名后（内容不变）
cp product.jpg product_copy.jpg
sha256sum product_copy.jpg
# a1b2c3d4e5f6...  ← ✅ 哈希相同！

# 微信压缩后（内容变了）
# (假设微信改变了图片质量)
sha256sum product_wechat.jpg
# 9z8y7x6w5v4u...  ← ❌ 哈希不同！
```

---

### 3.3 碰撞概率（会不会误判？）

**问题**：两个不同的文件会不会有相同的哈希？

**答案**：理论上可能，但概率**极其极其低**

```text
SHA-256 哈希空间：2^256 种可能

碰撞概率：
- 要找到 2 个文件有相同哈希
- 需要生成约 2^128 个文件
- = 340,282,366,920,938,463,463,374,607,431,768,211,456 个文件

对比：
- 全世界所有数据加起来 ≈ 2^70 字节
- 要产生碰撞需要的数据量 ≈ 2^128
- 差距：2^58 倍（约 2 亿亿倍）

结论：实际上不可能碰撞
```

**比喻**：
```text
碰撞的概率 ≈ 
在太平洋里随机扔一个原子，
然后再扔一个原子，
两个原子正好碰到一起的概率。
```

## 四、前端实现（浏览器）

### 4.1 完整代码

```typescript
// utils/fileHash.ts

/**
 * 计算文件的 SHA-256 哈希
 * @param file - 文件对象
 * @returns 64位十六进制哈希字符串
 */
export async function calculateFileHash(file: File): Promise<string> {
  // 1. 读取文件内容为 ArrayBuffer
  const buffer = await file.arrayBuffer();
  
  // 2. 使用 Web Crypto API 计算 SHA-256
  const hashBuffer = await crypto.subtle.digest('SHA-256', buffer);
  
  // 3. 转换为十六进制字符串
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  const hashHex = hashArray
    .map(byte => byte.toString(16).padStart(2, '0'))
    .join('');
  
  return hashHex;
}

/**
 * 使用示例
 */
async function example() {
  const file1 = document.querySelector('input[type="file"]').files[0];
  const hash1 = await calculateFileHash(file1);
  
  console.log('文件哈希:', hash1);
  // 输出: a1b2c3d4e5f6...（64个字符）
}
```

### 4.2 大文件优化（分块哈希）

```typescript
/**
 * 大文件分块计算哈希（带进度）
 */
export async function calculateFileHashWithProgress(
  file: File,
  onProgress?: (percent: number) => void
): Promise<string> {
  const chunkSize = 2 * 1024 * 1024; // 2MB 一块
  const chunks = Math.ceil(file.size / chunkSize);
  
  // 使用 FileReader API 分块读取
  const hashChunks: string[] = [];
  
  for (let i = 0; i < chunks; i++) {
    const start = i * chunkSize;
    const end = Math.min(start + chunkSize, file.size);
    const chunk = file.slice(start, end);
    
    // 计算每块的哈希
    const buffer = await chunk.arrayBuffer();
    const hashBuffer = await crypto.subtle.digest('SHA-256', buffer);
    const hashArray = Array.from(new Uint8Array(hashBuffer));
    const hashHex = hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
    
    hashChunks.push(hashHex);
    
    // 更新进度
    if (onProgress) {
      onProgress(Math.round(((i + 1) / chunks) * 100));
    }
  }
  
  // 所有块的哈希再次哈希（组合）
  const combinedHash = hashChunks.join('');
  const finalBuffer = new TextEncoder().encode(combinedHash);
  const finalHashBuffer = await crypto.subtle.digest('SHA-256', finalBuffer);
  const finalHashArray = Array.from(new Uint8Array(finalHashBuffer));
  
  return finalHashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}

/**
 * 使用示例（带进度条）
 */
async function uploadWithProgress(file: File) {
  const hash = await calculateFileHashWithProgress(file, (percent) => {
    console.log(`计算哈希进度: ${percent}%`);
    updateProgressBar(percent);
  });
  
  console.log('哈希计算完成:', hash);
}
```

### 4.3 前端 UI 组件

```tsx
// components/MediaUploader.tsx

import { calculateFileHash } from '@/utils/fileHash';

export function MediaUploader() {
  const [uploading, setUploading] = useState(false);
  const [progress, setProgress] = useState(0);
  
  async function handleFileSelect(event: ChangeEvent<HTMLInputElement>) {
    const file = event.target.files?.[0];
    if (!file) return;
    
    setUploading(true);
    setProgress(0);
    
    try {
      // 1. 计算文件哈希
      setProgress(10);
      const fileHash = await calculateFileHash(file);
      console.log('文件哈希:', fileHash);
      
      // 2. 检查是否已存在（秒传检测）
      setProgress(30);
      const checkResponse = await fetch('/api/media/check', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          fileHash,
          fileName: file.name,
          fileSize: file.size
        })
      });
      
      const checkResult = await checkResponse.json();
      
      if (checkResult.exists) {
        // ✅ 文件已存在，秒传！
        setProgress(100);
        toast.success('文件已存在，秒传成功！');
        onUploadComplete(checkResult.mediaId, checkResult.ossUrl);
        return;
      }
      
      // 3. 文件不存在，上传
      setProgress(50);
      const formData = new FormData();
      formData.append('file', file);
      formData.append('fileHash', fileHash);
      
      const uploadResponse = await fetch('/api/media/upload', {
        method: 'POST',
        body: formData
      });
      
      const uploadResult = await uploadResponse.json();
      
      setProgress(100);
      toast.success('上传成功！');
      onUploadComplete(uploadResult.mediaId, uploadResult.ossUrl);
      
    } catch (error) {
      console.error('上传失败:', error);
      toast.error('上传失败');
    } finally {
      setUploading(false);
    }
  }
  
  return (
    <div>
      <input
        type="file"
        accept="image/*,video/*"
        onChange={handleFileSelect}
        disabled={uploading}
      />
      
      {uploading && (
        <div className="progress-bar">
          <div className="progress-fill" style={{ width: `${progress}%` }}>
            {progress}%
          </div>
        </div>
      )}
    </div>
  );
}
```

## 五、后端实现（NestJS）

### 5.1 Backend API

```typescript
// src/media/media.controller.ts

import { Controller, Post, Body } from '@nestjs/common';
import { MediaService } from './media.service';

@Controller('media')
export class MediaController {
  constructor(private readonly mediaService: MediaService) {}
  
  /**
   * 检查文件是否已存在（秒传检测）
   */
  @Post('check')
  async checkFile(@Body() dto: CheckFileDto) {
    const { fileHash, fileName, fileSize } = dto;
    
    // 查询数据库
    const media = await this.mediaService.findByHash(fileHash);
    
    if (media) {
      // ✅ 文件已存在
      return {
        exists: true,
        mediaId: media.id,
        ossUrl: media.ossUrl,
        message: '文件已存在，秒传成功'
      };
    }
    
    // ❌ 文件不存在
    return {
      exists: false,
      message: '需要上传'
    };
  }
  
  /**
   * 上传新文件
   */
  @Post('upload')
  @UseInterceptors(FileInterceptor('file'))
  async uploadFile(
    @UploadedFile() file: Express.Multer.File,
    @Body('fileHash') fileHash: string,
    @CurrentUser() user: User
  ) {
    // 1. 再次检查（防止并发上传）
    const existing = await this.mediaService.findByHash(fileHash);
    if (existing) {
      return {
        mediaId: existing.id,
        ossUrl: existing.ossUrl,
        message: '文件已存在'
      };
    }
    
    // 2. 验证哈希（安全检查）
    const actualHash = await this.mediaService.calculateHash(file.buffer);
    if (actualHash !== fileHash) {
      throw new BadRequestException('文件哈希不匹配');
    }
    
    // 3. 上传到 OSS
    const ossObjectKey = `media/${this.getDatePath()}/${fileHash}${this.getExtension(file.originalname)}`;
    const ossUrl = await this.ossService.upload(file.buffer, ossObjectKey);
    
    // 4. 提取元数据
    const metadata = await this.mediaService.extractMetadata(file);
    
    // 5. 保存到数据库
    const media = await this.mediaService.create({
      fileHash,
      fileName: file.originalname,
      ossUrl,
      ossObjectKey,
      fileSize: file.size,
      mimeType: file.mimetype,
      metadata,
      uploadedBy: user.id
    });
    
    return {
      mediaId: media.id,
      ossUrl: media.ossUrl,
      message: '上传成功'
    };
  }
}
```

### 5.2 后端验证哈希

```typescript
// src/media/media.service.ts

import * as crypto from 'crypto';

export class MediaService {
  /**
   * 计算文件哈希（后端验证）
   */
  calculateHash(buffer: Buffer): string {
    return crypto
      .createHash('sha256')
      .update(buffer)
      .digest('hex');
  }
  
  /**
   * 查询文件是否存在
   */
  async findByHash(fileHash: string) {
    return this.prisma.mediaLibrary.findUnique({
      where: { fileHash }
    });
  }
}
```

## 七、常见问题

### Q1：修改图片文件名，哈希会变吗？

**A**：❌ 不会变

```bash
product.jpg      → hash: a1b2c3d4...
product_copy.jpg → hash: a1b2c3d4...  # 相同
```

**原因**：哈希只计算文件**内容**，不包括文件名

---

### Q2：图片旋转 90 度，哈希会变吗？

**A**：✅ 会变

```bash
原图.jpg              → hash: a1b2c3d4...
旋转90度后.jpg        → hash: xyz123ab...  # 不同
```

**原因**：旋转后，像素数据改变了

---

### Q3：只修改 EXIF 信息（不改图片内容），哈希会变吗？

**A**：✅ 会变

```bash
原图.jpg (带 GPS、相机型号等 EXIF)     → hash: a1b2c3d4...
删除 EXIF 后.jpg                       → hash: xyz123ab...  # 不同
```

**原因**：EXIF 信息也是文件的一部分

---

### Q4：哈希计算会很慢吗？

**A**：取决于文件大小

```text
图片（1MB）：    < 100ms  ✅ 很快
图片（10MB）：   < 500ms  ✅ 可接受
视频（100MB）：  < 5s     ⚠️ 需要进度条
视频（1GB）：    < 30s    ⚠️ 需要优化（分块计算）
```

---

### Q5：前端计算哈希安全吗？会不会被篡改？

**A**：后端需要**再次验证**

```typescript
// 前端：计算哈希
const fileHash = await calculateFileHash(file);

// 前端：上传文件 + 哈希
await upload(file, fileHash);

// 后端：再次计算，验证是否匹配
const actualHash = calculateHash(file.buffer);
if (actualHash !== fileHash) {
  throw new Error('哈希不匹配，文件可能被篡改');
}
```
