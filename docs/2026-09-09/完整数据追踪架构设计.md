# 完整数据追踪架构设计

> 更新日期：2026-09-09  
> 核心目标：完整记录创意输入 → 生成结果，用于后续打分和数据分析

---

## 一、核心理念

### 你的正确理解：

```text
1. 视频必须下载到创意电脑
   → ComfyUI 自动下载（或手动下载按钮）
   → 创意删不删是他们自己的事

2. 我们要完整记录所有数据
   → 创意上传了什么（输入）
   → 系统生成了什么（输出）
   → 创意改了几次参数（过程）
   → 最终效果好不好（打分）
   
3. 用于后续分析
   → 哪些 Prompt 效果好？
   → 哪些参数组合成功率高？
   → 哪个创意的转化率高？
   → 如何优化 Workflow？
```

## 二、完整数据模型设计

### 2.1 Task（任务表）- 核心记录

```typescript
model Task {
  id              String      @id @default(uuid())
  
  // ========== 归属信息 ==========
  userId          String
  user            User        @relation(fields: [userId], references: [id])
  
  projectId       String?     // 属于哪个项目
  campaignId      String?     // 属于哪个营销活动
  
  // ========== Workflow 信息 ==========
  workflowId      String
  workflowVersion String
  
  // ========== 任务模式 ==========
  mode            TaskMode    @default(PREVIEW)  // preview | production
  
  // ========== 输入数据（完整记录） ==========
  inputAssets     Json        // 创意上传的所有素材
  /*
  {
    "productImage": {
      "url": "https://oss.../product.jpg",
      "uploadedAt": "2026-09-09T10:00:00Z",
      "fileSize": 1024000,
      "dimensions": "1024x1024"
    },
    "referenceVideo": {
      "url": "https://oss.../ref.mp4",
      "uploadedAt": "2026-09-09T10:05:00Z",
      "duration": 5
    }
  }
  */
  
  params          Json        // 创意设置的所有参数
  /*
  {
    "prompt": "产品从水面缓缓浮现，水花飞溅，柔和光线",
    "negativePrompt": "模糊，变形",
    "duration": 5,
    "ratio": "16:9",
    "motionStrength": 0.8,
    "cameraMovement": "zoom_in",
    "seed": 12345
  }
  */
  
  // ========== 执行信息 ==========
  status          TaskStatus  @default(PENDING)
  
  provider        String?     // "seedance" | "minimax" | "kling"
  model           String?     // "doubao-seedance-2-5-260628"
  providerTaskId  String?
  
  // ========== 输出数据（完整记录） ==========
  outputAssets    Json?       // 生成的所有输出
  /*
  {
    "video": {
      "url": "https://oss.../output.mp4",
      "providerUrl": "https://provider.com/temp/video.mp4",
      "fileSize": 5120000,
      "duration": 5.2,
      "resolution": "1920x1080",
      "fps": 30,
      "generatedAt": "2026-09-09T10:15:00Z"
    },
    "thumbnail": {
      "url": "https://oss.../thumb.jpg"
    }
  }
  */
  
  // ========== 费用信息 ==========
  cost            Float?
  costStatus      String?     // "confirmed" | "unavailable"
  providerUsage   Json?       // Provider 返回的原始 usage
  /*
  {
    "tokens": 150,
    "video_seconds": 5,
    "api_version": "v3"
  }
  */
  
  // ========== 质量评分（后续打分用） ==========
  qualityScore    Float?      // 0-100 分
  scoredBy        String?     // 谁打的分（user_id）
  scoredAt        DateTime?
  scoreNote       String?     // 打分备注
  
  // ========== 业务标签（用于分析） ==========
  tags            String[]    // ["新品上市", "抖音", "15秒"]
  category        String?     // "产品视频" | "品牌宣传" | "用户教育"
  
  // ========== 使用统计（追踪效果） ==========
  viewCount       Int         @default(0)    // 被查看次数
  downloadCount   Int         @default(0)    // 被下载次数
  publishedAt     DateTime?   // 发布到平台时间
  platformData    Json?       // 平台数据（播放量、点赞数等）
  /*
  {
    "platform": "douyin",
    "publishedUrl": "https://douyin.com/video/123",
    "views": 10000,
    "likes": 500,
    "shares": 50,
    "comments": 20,
    "conversionRate": 0.05  // 转化率
  }
  */
  
  // ========== 修改历史（记录调参过程） ==========
  revisionCount   Int         @default(0)    // 修改了几次
  parentTaskId    String?     // 如果是重新生成，指向原任务
  
  // ========== 时间戳 ==========
  createdAt       DateTime    @default(now())
  submittedAt     DateTime?   // 提交给 Provider 时间
  completedAt     DateTime?   // 完成时间
  
  // ========== 关联 ==========
  revisions       Task[]      @relation("TaskRevisions", references: [parentTaskId])
  parent          Task?       @relation("TaskRevisions", fields: [parentTaskId], references: [id])
  
  @@index([userId])
  @@index([workflowId])
  @@index([status])
  @@index([mode])
  @@index([createdAt])
  @@index([qualityScore])
}

enum TaskMode {
  PREVIEW       // 快速预览
  PRODUCTION    // 正式生成
}

enum TaskStatus {
  PENDING       // 等待处理
  RUNNING       // 处理中
  COMPLETED     // 完成
  FAILED        // 失败
}
```

### 2.2 TaskRevisionHistory（参数调整历史）

记录创意每次修改参数的过程：

```typescript
model TaskRevisionHistory {
  id          String   @id @default(uuid())
  
  taskId      String
  task        Task     @relation(fields: [taskId], references: [id])
  
  revision    Int      // 第几次修改（1, 2, 3...）
  
  // 修改了什么
  changedFields Json
  /*
  {
    "prompt": {
      "old": "产品从水面浮现",
      "new": "产品从水面缓缓浮现，水花飞溅"
    },
    "motionStrength": {
      "old": 0.5,
      "new": 0.8
    }
  }
  */
  
  // 完整的新参数
  newParams   Json
  
  // 修改原因（可选，创意填写）
  reason      String?  // "第一次太快了，改慢一点"
  
  createdAt   DateTime @default(now())
  
  @@index([taskId])
}
```

### 2.3 MediaLibrary（素材库）

记录创意上传的所有素材：

```typescript
model MediaLibrary {
  id            String      @id @default(uuid())
  
  // 素材信息
  name          String
  type          MediaType
  
  // 文件信息
  ossUrl        String      // OSS 永久 URL
  objectKey     String      // OSS 对象键
  fileSize      Int         // 文件大小（字节）
  
  // 媒体元数据
  metadata      Json?
  /*
  图片：
  {
    "width": 1024,
    "height": 1024,
    "format": "jpg",
    "colorSpace": "RGB"
  }
  
  视频：
  {
    "duration": 5.2,
    "resolution": "1920x1080",
    "fps": 30,
    "codec": "h264"
  }
  */
  
  // 业务信息
  tags          String[]    // ["产品图", "化妆品", "50ml"]
  category      String?     // "产品图" | "参考视频" | "Logo"
  
  // 使用统计
  usageCount    Int         @default(0)  // 被使用了多少次
  
  // 上传信息
  uploadedBy    String
  user          User        @relation(fields: [uploadedBy], references: [id])
  
  projectId     String?     // 属于哪个项目
  
  createdAt     DateTime    @default(now())
  
  @@index([type])
  @@index([uploadedBy])
  @@index([projectId])
}

  BACKGROUND          // 背景
```

```typescript
model TaskFeedback {
```

### 4.2 参数组合分析

```typescript
// GET /api/analytics/best-params

// 统计高分任务的参数分布
const analysis = await prisma.$queryRaw`
  SELECT 
    params->>'duration' as duration,
    params->>'motionStrength' as motion,
    AVG(quality_score) as avg_score,
    COUNT(*) as count
  FROM tasks
  WHERE quality_score >= 80
  GROUP BY duration, motion
  ORDER BY avg_score DESC
`;

return {
  bestCombinations: [
```

### 4.3 创意人员排行榜

```typescript
// GET /api/analytics/creator-leaderboard

const leaderboard = await prisma.user.findMany({
  include: {
    tasks: {
      where: {
        status: "COMPLETED",
        qualityScore: { not: null }
      }
    }
  }
});

return leaderboard.map(user => ({
  name: user.name,
  totalTasks: user.tasks.length,
  avgScore: average(user.tasks.map(t => t.qualityScore)),
  approvalRate: user.tasks.filter(t => t.approved).length / user.tasks.length,
  totalCost: sum(user.tasks.map(t => t.cost))
})).sort((a, b) => b.avgScore - a.avgScore);
```
